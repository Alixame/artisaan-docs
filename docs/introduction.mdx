## O que você vai usar

A renderização de `.mdx` neste projeto já suporta componentes de interface prontos.
Com isso, você consegue criar páginas visuais sem construir layout do zero.

| Componente | Uso principal |
| --- | --- |
| `DocHeader` | Cabeçalho da página (título + descrição) |
| `CodeBlock` | Blocos de comando com cópia |
| `CodeTabs` + `CodeTabItem` | Código por plataforma/contexto em abas |
| `Steps` + `Step` | Fluxos em etapas com destaque visual |

## Estrutura mínima de um arquivo `.mdx`

<CodeBlock>
{`---
title: "Minha Página"
description: "Resumo curto"
lastUpdated: 2026-03-02
---

<DocHeader
  title="Minha Página"
  description="Resumo curto"
/>

## Seção

Texto da documentação.`}
</CodeBlock>
